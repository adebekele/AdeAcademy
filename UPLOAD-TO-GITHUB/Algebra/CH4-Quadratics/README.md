# Algebra / CH4-Quadratics

An interactive classroom review app for Chapter 4 quadratics.

## What It Includes

- Fluency practice for solving and factoring quadratics
- Vieta/root-structure review
- Quadratic inequalities and domain restrictions
- Quadratic function-value problems
- Mixed review problems modeled after AoPS-style chapter review work
- Strategy prompts, progressive hints, answer checking, and full solutions
- Main Idea Review notes after each problem-set section
- Teacher panel with a suggested 60-minute lesson flow

## Run Locally

From this folder's parent directory, run:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8765/Algebra/CH4-Quadratics/index.html
```

If the server is already running from the parent folder, the URL above should work immediately.
