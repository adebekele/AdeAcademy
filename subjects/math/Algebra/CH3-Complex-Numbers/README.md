# Algebra / CH3-Complex-Numbers

An interactive classroom review app for Chapter 3 complex numbers.

## What It Includes

- Arithmetic of Complex Numbers: addition, multiplication, division, and powers of `i`
- The Complex Plane: coordinates, quadrants, distance, and midpoint
- Real and Imaginary Parts: identifying, comparing, and matching parts
- Graphing in the Complex Plane: plotting, graphing sets, movement, and reflection
- Strategy prompts, progressive hints, answer checking, and full solutions
- Main Idea Review notes after each problem-set section
- Teacher panel with a suggested 60-minute lesson flow

## Run Locally

From this folder's parent directory, run:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8765/Algebra/CH3-Complex-Numbers/index.html
```

If the server is already running from the parent folder, the URL above should work immediately.
