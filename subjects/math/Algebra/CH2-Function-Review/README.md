# Algebra / CH2-Function-Review

An interactive classroom review app for Chapter 2 function review.

## What It Includes

- Functions Basic: notation, evaluation, domain, and range
- Graphing Functions: intercepts, key features, point mapping, and transformations
- Composition: values, formulas, equations, and difference quotients
- Inverse Functions: inverse rules, tables, verification, and restricted domains
- Strategy prompts, progressive hints, answer checking, and full solutions
- Main Idea Review notes after each problem-set section
- Teacher panel with a suggested 60-minute lesson flow

## Run Locally

From this folder's parent directory, run:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8765/Algebra/CH2-Function-Review/index.html
```

If the server is already running from the parent folder, the URL above should work immediately.
